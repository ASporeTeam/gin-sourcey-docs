# gin-sourcey-docs

A **Sourcey-generated** documentation site for
[github.com/gin-gonic/gin](https://github.com/gin-gonic/gin) at the pinned commit
`0f09c3a9b4626d9fe9979cf4d0521d6ae32ab646` (2026-10-10, MIT).

**Live site:** https://asporeteam.github.io/gin-sourcey-docs/

## What is in here

| Path | What it is |
|---|---|
| `sourcey.config.ts` | The Sourcey build configuration (guides tab + godoc tab). |
| `godoc.json` | The Sourcey godoc snapshot (`schema_version: 1`) taken from the pinned clone. sha256 `91bfb81dff5fafadf8ea973ee99da82eb5bf0c82d0e0e854ea7e0a88bb070e15`. |
| `gin-src/` | The pinned `gin` clone (`git rev-parse HEAD` = `0f09c3a9b4626d9fe9979cf4d0521d6ae32ab646`), vendored so the reference is verifiable against the exact source it documents. |
| `introduction.md`, `coverage.md`, `gaps.md`, `reproduce.md` | The guide pages (the maintainer-facing findings are in `gaps.md`). |
| `dist/` | The published static site (the output of `sourcey build`). |
| `evidence.json`, `report.md` | The machine-readable evidence packet and the delivery report for this work. |

## Rebuild

```bash
npm install sourcey          # Sourcey v3.6.12 (Node >= 20)
npx sourcey build            # -> dist/
```

The Go API tab renders from `godoc.json` (`mode: "snapshot"`), so the build needs
no Go toolchain. To regenerate the snapshot from source:

```bash
cd gin-src && git rev-parse HEAD     # 0f09c3a9b4626d9fe9979cf4d0521d6ae32ab646
npx sourcey godoc -m . -p ./... -o ../../godoc.json
```
